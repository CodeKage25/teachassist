# Lessons

## 2026-07-22 — "State of the art" means visual ambition, not just hygiene
**Correction:** After a first UI pass (token migration, dark mode, component polish), the user said the design was "mid".
**Pattern:** I treated a design-system cleanup as the deliverable. Correct tokens, dark mode, and consistent spacing are the *floor* — they don't read as "state of the art" to a user looking at the page.
**Rule:** When asked for a state-of-the-art / greatly improved UI, ship visible design ambition: atmosphere (gradient glows, grid textures), motion (scroll reveals, hover lift/scale), varied layout rhythm (bento grids, asymmetry), gradient accents, and glass/elevation depth — especially on the landing page and first dashboard screen, which are what gets judged. Benchmark against Linear/Stripe/Vercel landing pages before calling it done.
